# AI Agent Initialization Guide

## First Chat Session Only

**IMPORTANT**: This instruction is for the FIRST chat session only. Subsequent sessions should skip this step to save requests.

### Required Reading for Context
1. **Read `AGENTS.md` first** - This contains the complete project context, AI agent roles, and interaction guidelines
2. **Load additional documentation as needed**:
   - `PROJECT_STRUCTURE.md` - When discussing code organization or architecture
   - `CODE_CONVENTIONS.md` - When reviewing code style or providing coding guidance  
   - `GAME_DESIGN.md` - When discussing game mechanics or features
   - `API_REFERENCE.md` - When working with internal APIs or interfaces

### After First Session
- **Skip reading AGENTS.md** (context already established)
- **Only load specific .md files** when their content is directly relevant to the current discussion
- **Reference previous context** from the conversation history
